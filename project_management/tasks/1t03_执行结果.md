## 二、核心接口摘要

### 2.1 `src/strategies.py`

| 符号 | 类型 | 职责说明 |
| --- | --- | --- |
| `calc_notional` / `calc_commission` / `calc_stamp_duty` | 函数 | 使用 `Decimal` 避免浮点误差；佣金按 `max(notional * commission_rate, min_commission)` 计算，印花税按 `stamp_duty_rate`（配置为 `0.0`）计算 |
| `max_affordable_shares` | 函数 | 计算满足 `notional + commission + stamp_duty <= budget` 的最大 `lot_size`（100 股）整数倍；支持 `commission_free=True` 用于除息再投 |
| `compute_symbol_indicators` | 函数 | 基于 `data_loader.build_forward_adjusted_daily` 输出的前复权序列计算严格 `shift(1)` 的 `prev_55d_high`、`prev_20d_low`、`atr20`，并除以当日 `adj_factor[T]` 映射至 `T` 日现货价空间（消除未来公司行为干扰，保证全跑与分段跑一致） |
| `TurtleConfig` / `TurtleSignal` | 数据类 | 海龟参数配置与单日判定输出结构 |
| `compute_turtle_risk_shares` | 函数 | 计算风险定仓股数 `floor((account_equity * 0.01) / atr20 / lot_size) * lot_size` |
| `evaluate_turtle_bar` | 函数 | 海龟单日撮合判定：空仓且 `High >= prev_55d_high` 按 `max(Open, prev_55d_high)` 买入，股数取 `min(risk_shares, cap_shares, cash_affordable_shares)`；持仓且 `Low <= prev_20d_low` 按 `min(Open, prev_20d_low)` 卖出全部可卖持仓 |
| `GridConfig` / `GridOrder` / `GridState` / `GridFill` | 数据类 | 网格参数与可无损 JSON 序列化的挂单簿状态结构 |
| `compute_grid_step` / `grid_level_price` | 函数 | 计算锁定步长 `clip(atr20 / P0, step_min, step_max)` 与几何档位价（下方 `P0*(1-s)^k`、上方 `P0*(1+s)^k`） |
| `initialize_grid` | 函数 | 建网当日以 `Close` 为中枢 `P0`、买入 `initial_slices=2` 份（预算总分 `total_slices=5` 份），并布设下方 3 档买单与上方 2 档卖单 |
| `apply_split_to_grid` | 函数 | 拆股生效日同步按 `factor` 折算锚定价、挂单触发价与卖单目标股数 |
| `match_grid_bar` | 函数 | 后续交易日盘中撮合：`Low <= buy_price` 按 `min(Open, buy_price)` 买入并在 `level + 1` 补挂卖单；`High >= sell_price` 按 `max(Open, sell_price)` 卖出并在 `level - 1` 补挂买单；新挂反向单次交易日生效，杜绝同日回转与档位冲突 |

### 2.2 `src/engine.py`

| 符号 | 类型 | 职责说明 |
| --- | --- | --- |
| `ACCOUNT_IDS` / `ACCOUNT_TYPES` | 常量 | 定义 5 个同口径虚拟账户：`A`（`routed`）、`B1`（`pure_turtle`）、`B2`（`pure_grid`）、`C`（`sector_equal_bh`）、`D`（`benchmark_bh`） |
| `normalize_regime` / `resolve_regime_for_date` | 函数 | 校验路由态合法性、将 `UNRATED` 映射为 `TRANSITION`，并支持按日期键映射（阶梯生效）或标的键映射的 `regime_schedule`（默认回落至 `watchlist.json` 的 `current_regime`） |
| `Position` / `SymbolStrategyState` / `AccountState` | 数据类 | 单标的持仓、策略状态与单账户账本结构，均提供 `to_dict()` / `from_dict()` 纯 JSON 原语序列化 |
| `SimulationEngine` | 类 | 核心按日推进引擎，提供 `step_day`、`run`、`export_state`、`from_state`、`get_summary`；每日严格按 4 步执行（1. 盘前拆股与除息免佣再投 -> 2. 开盘 A 组路由切换/`TRAP_OFF` 强平及 C/D 起始建仓 -> 3. 盘中海龟/网格触价及收盘新网初始化 -> 4. 收盘估值、`equity`/`nav`/`cum_return`/`max_drawdown`/`A_vs_B1/B2/C/D` 超额收益核算与双守恒自检） |
| `run_simulation` | 函数 | 便捷入口函数，支持从任意 `start_date` 运行或由 `initial_state` 恢复续跑并返回 `SimulationEngine` |
