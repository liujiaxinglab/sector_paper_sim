## 交付与规则覆盖

| 事项 | 实现与实测 |
| --- | --- |
| `ISS-003` 路由清仓 | A 组每日按 `effective_date <= T` 解析路由，`UNRATED` 映射为 `TRANSITION`。切入空仓态或跨有效策略态时按开盘价全额卖出旧仓，含拆分后的零股。 |
| `ISS-004` 分红复投 | 份额折算先于分红入账。复投资金同时受分红额度及账户现金约束，计万二佣金和 `0.10` 元最低佣金。当日开盘清仓的标的只登记现金分红。 |
| `ISS-005` 网格 | 以开盘价建 `50%` 底仓，用截至前一日的前复权 `ATR20 / close` 锁定步长及 `0.015` 下限，按等差价格布单。阳线和平盘先低后高，阴线先高后低。测试覆盖跳空价、实时现金约束、当日买份锁定及反向补单次交易日生效。 |
| `ISS-006` 海龟 | 用信号日收盘与此前 `55` 日最高收盘价或 `20` 日最低收盘价比较。后续开盘按前日权益的 `1/6` 和可用现金整手定仓，离场卖出全部可卖份额。 |
| 停牌顺延与收盘核算 | 停牌日仍记拆分和分红，开盘意图延至复牌首日，期间按最近前收估值。待清仓动作独立保留，复牌开盘清仓后按当日生效路由继续。C、D 按标的首次买入后持有。收盘分别核对现金与权益变动，合成测试注入差额验证两项检查均能报错。 |
| `ISS-007`、`ISS-009` 日频与复现 | 新入口支持 `--config`、`--output-dir`、`--as-of`、`--from-scratch`、`--allow-lag`、`--dry-run`，默认从配置的 `2026-11-23` 起算至全池最新行情日。周频入口已删除，旧断点须从头重建。日频断点仅保存截面、待执行动作和成交计数，合成六行业样本小于 800 行。 |
